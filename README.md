# ディアボロの大冒険 ver0.13（勝手移植版）

https://newdtw2.github.io/

これはGitHub上で公開されていた[「ディアボロの大冒険 0.13」のWeb移植版](https://github.com/newDTW/newDTW.github.io)をベースに、個人的に引き継いで改良したものです。

遊ぶ際は個人でひっそりと楽しんでいただき、外部への積極的な発信・共有・公開は控えてください。

## 基本操作

| キー | 操作 |
| :---: | :--- |
| <kbd>Z</kbd> | 攻撃・決定 |
| <kbd>X</kbd> | ダッシュ・キャンセル |
| <kbd>A</kbd> | コマンドウィンドウ |
| <kbd>C</kbd> | 向き変更 |
| <kbd>Shift</kbd> | 斜め移動・ソート |
| <kbd>S</kbd> | 射撃 |
| <kbd>Space</kbd> | 地図 |
| <kbd>F</kbd> | FF発動 |

## 特殊操作方法

| キー | 操作 |
| :---: | :--- |
| <kbd>F2</kbd> / <kbd>F3</kbd> | BGM音量の調整 |
| <kbd>F4</kbd> / <kbd>F5</kbd> | 効果音音量の調整 |
| <kbd>F7</kbd> | BGMのON/OFF |

※ <kbd>F1</kbd>, <kbd>F6</kbd>, <kbd>F12</kbd> はオミットしました。

## 主な変更点
- 引き継ぎ前のバグ修正
- チート機能の追加
- テンキーによる8方向移動に対応
- ゲームパッドでの操作に対応
- スマートフォンでの操作に対応（動作は重め）
