これはGitHub上で公開されていた「ディアボロの大冒険 0.13」のWeb移植版（※）をベースに、個人的に引き継いで改良したものです。

細かい不具合が残っているかもしれませんが、モチベが下がってきたので一旦リリースします。

主な変更点
- バグ修正
- チート機能の追加
- テンキーによる8方向移動に対応
- ゲームパッドでの操作に対応
- スマートフォンでの操作に対応（動作は重め）
- 亀の中のBGM

特殊操作方法
- F2、F3でBGMの音量調整
- F4、F5で効果音の音量調整
- F7でBGMのON/OFF
- F1、F6、F12は何も起こりません

CORSエラーが発生するため、実行にはローカルサーバーなどが必要です。
遊ぶ際はローカル環境またはプライベートネットワーク上で実行し、外部へ公開しないでください。
